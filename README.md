# PerceptronVisualizer

Учебно-демонстрационное Qt6-приложение для наглядной классификации двумерного объекта многослойным пороговым персептроном. Интерфейс выполнен в строгом стиле для использования на защите и в учебной демонстрации: элементы управления, оси, границы и схема сети чёрно-белые, а области классов выделяются синим и красным цветом.

Обучения в проекте нет. Границы классов задаются детерминированными весами и смещениями. Пользователь сначала выбирает режим, затем предъявляет объект по координатам. После нажатия кнопки «Распознать» приложение выдаёт результат. Отображение объекта на плоскости включается отдельной кнопкой и используется как визуальное подтверждение распознавания.

## Структура сети

- первый слой: H1-H6;
- второй слой: S1-S2;
- выходной слой: O1.

Простые режимы получаются включением нужной части нейронов и связей. Параметры H-нейронов можно менять вручную во вкладке «Параметры H».

## Режимы

1. 1 нейрон — одна разделяющая прямая.
2. 2 слоя: 2->1 — пересечение двух полуплоскостей.
3. 2 слоя: 3->1 — треугольная область.
4. 2 слоя: 4->1 — четырёхугольная область.
5. 3 слоя: две области A и B: область A — класс 1, область B — класс 2, вне A и B — не принадлежит ни одному классу.
6. 3 слоя: B и не A.
7. 3 слоя: A или B.
8. 3 слоя: A и B.
9. 3 слоя: A и не B.

## Что показывает программа

- выбранный режим распознавания;
- координаты предъявленного объекта x1 и x2;
- результат распознавания по координатам без предварительного отображения точки на плоскости;
- отдельную визуализацию распознанного объекта по кнопке;
- области классов и разделяющие прямые;
- значения H1-H6, S1-S2, O1;
- чёрно-белую подсветку активных нейронов и связей;
- числовые подписи на осях координат;
- цветовое выделение областей классов: в режиме распознавания двух классов синий — класс 1, красный — класс 2, нейтральный фон — вне заданных классов;
- легенду с цветами классов;
- текстовое объяснение решения.

## Сборка

Откройте `CMakeLists.txt` в Qt Creator, выберите комплект Qt6 и соберите проект. После сборки исполняемый файл будет называться `PerceptronVisualizer`.
